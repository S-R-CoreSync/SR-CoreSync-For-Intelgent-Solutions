## 2) البدء السريع (Windows / PowerShell)

```powershell
# 1 · المتطلبات: Node 22+ · Git for Windows · Chrome · Python داخل .venv
#     (قياس فعلي 2026-11-28: Python 3.15.2 لا 3.13 — لا تعتمد على الرقم في الخطة القديمة)
.venv\Scripts\python.exe --version
node --version

# 2 · معاينة محلية (أصل نظيف بلا Service Worker)
.venv\Scripts\python.exe -m http.server 8083 --directory .
# ثم افتح http://127.0.0.1:8083/index.html

# 3 · قبل أي التزام: أعد توليد الطبقات وافحص
.venv\Scripts\python.exe scripts/preflight.py

# 4 · البناء الكامل (6 مراحل، ~6 دقائق)
node scripts/build.mjs

# 5 · بوابة ما قبل الدفع: 21 خطوة، ~2–6 دقائق (تتفاوت مع حِمل القرص)
& 'C:\Program Files\Git\bin\bash.exe' scripts/prepush_gate.sh
#     لم يبقَ أي استثناء: لا PYTEST_ADDOPTS ولا --ignore. ملف TTS يُتخطّى تلقائياً.
```

**قواعد غير قابلة للتفاوض:** لا `push` بلا بوابة خضراء + أمر صريح من المالك · لا تعديل ملف قبل عرض قائمة الملفات والفحوص (البروتوكول 1 في `PLAN.md`) · كل بند يُنجز يُسجّل في `worklog.md` ويُحذف من `PLAN.md`.

## 3) خط الأنابيب وأسبابه

| المرحلة | الأمر | ما يحكمه |
|---|---|---|
| `preflight` | `scripts/preflight.py` | يعيد توليد `partials/` و`en` من `index.html`، ثم يتحقق أن الشجرة تُعيد بناء نفسها: التوليد، التوافق، hreflang، الروابط، تزامن وسوم السكربت، وبصمات CSP |
| `build` | `scripts/build.mjs` | 6 مراحل: تحقق JS/CSS، CSP، Tailwind، مجموعة النشر، السنتينل (13 حارساً)، سلامة النشر + فحص الأسرار |

> **مزلق متكرر:** CSP يتقهقر إذا عدّلت سكربتاً مضمّناً ولم تُعِد التوليد. الترتيب الآمن: `prepare_publish_set` ← `build_csp` ← `build`.

> **قاعدة جديدة (2026-11-28):** أي فحص **حاجب** في `ci.yml` يجب أن يكون موجوداً في `prepush_gate.sh` وبنفس الحجبيّة. الاثنان انزاحا قبل اليوم: البريد كان حاجباً في CI وغائباً عن البوابة، فمرّت `CI & QA` حمراء سبع دورات بينما البوابة خضراء.

الفحص البنيوي يقارن الآن ما يجب، و`--strict` يمرّ. لكن `--strict-all` لا يزال يرصد 28 صفحة بسبب **كثافة محتوى تجاري مختلفة**، وهي مسألة منتج لا بنية:

- التخطيط في اللغات **أقدم**؛ والماستر أُعيدت هيكلته ولم تُرحَّل اللغات.
- **ليست تكراراً آلياً** يمكن حذفه بأمان: النصوص مترجمة والبطاقات تحمل أسعاراً. القرار منتجيّ: أي النسختين تُعتمد؟

عند الحسم: إما ترحيل اللغات إلى بنية الماستر، أو تحديث الماستر ليطابق ما تبيعه اللغات، ثم `--strict-all` يُشغَّل حاجباً ويُغلق الملف نهائياً.

## 6) المزالق المعروفة (اقرأها قبل أي تعديل)

- **تزامن الجلسات:** أكثر من جلسة عملت على نفس الشجرة؛ إحداها دفعت والتزمت ملفاتي. قبل أي `commit` شغّل `git status` وتأكد أنك لا تُدرج ملفات غيرك (خصوصاً `sr_agent_server.py` و`js/sr-agent-widget.js`).
- **قفل `_site`:** خوادم المعاينة (`http.server`) تُمسك المجلد فيفشل `prepare_publish_set` بـ`WinError 5`. أوقف كل عمليات `http.server` قبل البناء.
- **`showcase-img`:** صور المؤسسين تحمل نفس الصنف؛ أي قاعدة تستهدف الصنف ستحلّ محل صورهم. الشرط الصحيح: `logo-official` داخل الوسم.
- **الاختبارات البطيئة:** السنتينل يتراوح 128s–396s حسب حِمل الجهاز — لذلك مهلة الخطوة 600s.
- **التحقق البصري:** `browser_tool` يفشل إن لم تكن النافذة معروضة. البديل: Chrome headless عبر CDP (`scratch/cdp_*.js`، `scripts/measure-cockpit-windows.mjs`) مع قياس `getBoundingClientRect`.
- **البوابة ليست CI:** قد تكون خضراء وCI أحمر. عند كل `[FAIL]` في CI: اسأل أولاً «هل هذه الخطوة في البوابة؟» قبل التخمين في الكود. فحوص المتصفح الثلاثة تبقى CI فقط (تحتاج Chromium).
- **تبويب CDP واحد لا يحتمل الموقع:** كل انتقال بين الصفحات الثقيلة يستغرق 5–9 ثوانٍ، وبعد صفحتين يتوقف المؤشر فيبدو الموقع «متجمّداً» وهو ليس كذلك. للقياسات المتعددة: جلسة Chrome نظيفة لكل لغة (كما في `scratch/diag-lang.mjs`).
- **Service Worker أثناء القياس:** يُعطّل عبر `Network.setBypassServiceWorker` وإلا قِست نسخة الكاش لا الملف الحقيقي.
- **نسخة كاش CSS:** تعديل ملف CSS بلا رفع `?v=` يعني أن الزائر العائد يحتفظ بالقديم. المرجع في `index.html` ثم `partials/00-gap.html`، والصفحات الـ28 تُحدَّث نصياً (لا `sync_locales`).
- **`--strict` مقابل `--strict-all`:** الأول يقارن البنية (ترتيب/وجود/تذييلات/`li`/`tr`/`h2h3`)، والثاني يضيف كثافة المحتوى (`cards`/`btn`). لا تقلب الثاني إلى حاجب قبل ترحيل التسعير.
