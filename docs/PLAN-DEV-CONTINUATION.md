## 2) البدء السريع (Windows / PowerShell)

```powershell
# 1 · المتطلبات: Node 22+ · Python 3.13 داخل .venv · Git for Windows · Chrome
.venv\Scripts\python.exe --version
node --version

# 2 · معاينة محلية (أصل نظيف بلا Service Worker)
.venv\Scripts\python.exe -m http.server 8083 --directory .
# ثم افتح http://127.0.0.1:8083/index.html

# 3 · قبل أي التزام: أعد توليد الطبقات وافحص
.venv\Scripts\python.exe scripts/preflight.py

# 4 · البناء الكامل (6 مراحل، ~6 دقائق)
node scripts/build.mjs

# 5 · بوابة ما قبل الدفع (20 خطوة، ~9–11 دقيقة)
$env:PYTEST_ADDOPTS='--ignore=tests/test_tts_e2e.py'
& 'C:\Program Files\Git\bin\bash.exe' scripts/prepush_gate.sh
```

**قواعد غير قابلة للتفاوض:** لا `push` بلا بوابة خضراء + أمر صريح من المالك · لا تعديل ملف قبل عرض قائمة الملفات والفحوص (البروتوكول 1 في `PLAN.md`) · كل بند يُنجز يُسجّل في `worklog.md` ويُحذف من `PLAN.md`.
